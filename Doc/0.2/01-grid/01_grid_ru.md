# Grid

12-колоночная сетка: строк неограниченно, ширина колонки — доля 1/12 доступного
пространства, зазор между ячейками — `Style.Gap` сетки, внешний отступ — `Style.Padding`.
Размещение ячеек — auto-flow слева направо, сверху вниз, с обходом уже занятых объединением по
строкам зон.

`RimUI.Layout.Grid : UiElement`

## Пример

```csharp
var grid = new Grid();
grid.Cell(6, new Text("Левая половина"));   // colSpan=6 из 12 -> 50% ширины
grid.Cell(6, new Text("Правая половина"));
grid.Cell(4, 2, someTallContent);           // colSpan=4, rowSpan=2 - объединение по строкам
```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Columns` (const) | `int` | `12` | Число колонок сетки, фиксировано. |

Сетка сама по себе не имеет настраиваемых полей помимо унаследованного `Style` (см. страницу
«Style — модель стиля»): `Style.Gap` — зазор между ячейками, `Style.Padding` — внешний отступ.

## Точный алгоритм auto-placement

Размещение — это **next-fit**, а не bin-packing с возвратом назад: курсор (текущая строка/
колонка) движется только вперёд и никогда не возвращается назад, даже если раньше остался
подходящий промежуток.

- Если `ColSpan` ячейки не влезает в остаток текущей строки — ячейка переносится ЦЕЛИКОМ на
  новую строку (курсор сбрасывается на колонку 0 следующей строки), без попытки найти для неё
  место раньше.
- Если по ширине место есть, но конкретные колонки заняты (обычно из-за `RowSpan`-ячейки,
  нависающей сверху из предыдущей строки) — курсор сдвигается на одну колонку вправо и проверка
  повторяется, так ячейка может «обойти» занятую rowspan-зону в той же строке.
- **Из этого следуют «дыры» в сетке**: если в строке сначала легла ячейка на 8 колонок, а
  следующая ячейка на 6 колонок не влезает в оставшиеся 4 — она уходит на новую строку целиком, а
  4 оставшиеся колонки текущей строки остаются пустыми навсегда (курсор их уже «прошёл» и не
  вернётся). Это стоит учитывать при планировании раскладки — сумма `ColSpan` подряд идущих
  ячеек должна аккуратно делить 12, иначе появятся невидимые пропуски.
- Высота строки с `RowSpan > 1`: если суммы высот охваченных строк (+ зазоры) не хватает под
  желаемую высоту контента — весь недостаток добавляется ЦЕЛИКОМ в последнюю из охваченных строк,
  а не распределяется пропорционально по всем.

## Стили

Использует обычный `Style` (`UiElement.Style`) — фон/бордюр/скругление/отступы как у любого
элемента-контейнера. Собственного слота темы у `Grid` нет.

## Методы

| Метод | Возвращает | Описание |
|---|---|---|
| `Cell(GridCell cell)` | `Grid` | Добавить готовую ячейку. Возвращает себя (цепочка вызовов). |
| `Cell(int colSpan, UiElement content)` | `Grid` | Ячейка с содержимым и шириной в колонках (1..12). |
| `Cell(int colSpan, int rowSpan, UiElement content)` | `Grid` | То же + объединение по строкам. |
| `int CellCount` (свойство) | `int` | Число ячеек в сетке. |
| `GridCell CellAt(int i)` | `GridCell` | Ячейка по индексу добавления. |
| `RemoveCellAt(int i)` | `void` | Удалить ячейку по индексу добавления. |
| `ClearCells()` | `void` | Убрать все ячейки сразу. |

Динамическое управление ячейками (`CellAt`/`RemoveCellAt`/`ClearCells`) пригождается в редакторах
интерфейсов вроде конструктора интерфейсов из настроек мода.

## События

Собственных событий/колбэков нет.

## Поддержка механик

| Механика | Поддержка | Пояснение |
|---|---|---|
| Стиль (`Style`) | Да | Обычный `Style` контейнера (фон/бордюр/паддинг/gap). |
| Спрайт-рамка | Да | Через `Style.Sprite`, как у любого элемента. |
| Анимация (`Style.Animation`) | Да | Общий механизм `UiElement.EmitStyled`. |
| Тайлинг спрайта | Да | Если используется `Style.Sprite.Repeat`. |
| Disabled | Нет | Понятия «отключённой сетки» не существует. |
| Hover-fade | Нет | Сетка не реагирует на наведение сама по себе. |
| Drag&drop | Косвенно | Не у самой `Grid`, а у входящих в неё `GridCell` (см. страницу «GridCell»). |
