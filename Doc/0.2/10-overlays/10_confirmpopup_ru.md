# ConfirmPopup

Компактное подтверждение прямо у элемента-цели: сообщение и две кнопки, без модального окна на
весь экран.

`RimUI.Components.ConfirmPopup : UiElement`

## Когда что использовать

| Ситуация | Компонент |
|---|---|
| Действие обратимое и локальное: удалить строку, сбросить фильтр, очистить поле | `ConfirmPopup` |
| Действие необратимое или важное: удалить сохранение, применить изменения ко всей колонии | `ConfirmWindow` |

`ConfirmPopup` легко пропустить взглядом — он и рассчитан на то, чтобы не прерывать работу.
Именно поэтому для необратимого остаётся модальное окно, которое нельзя не заметить.

## Пример

```csharp
var deleteBtn = new Button { Content = new Text("Удалить"), Preset = ButtonPreset.Danger };

new ConfirmPopup
{
    Trigger = deleteBtn,
    Message = "Удалить выбранную запись? Действие нельзя отменить.",
    AcceptLabel = "Да",
    RejectLabel = "Нет",
    Danger = true,
    OnAccept = () => rows.RemoveAt(index)
};

// подтверждение справа от цели, с другой иконкой
new ConfirmPopup
{
    Trigger = resetBtn,
    Message = "Сбросить фильтры?",
    Icon = Icons.Info,
    Placement = OverlayPlacement.Right,
    OnAccept = ResetFilters
};
```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Key` | `string` | `null` | Ключ состояния в ID-store (см. «Ключ и состояние» на странице «Архитектура»). Нужен, если элемент пересоздаётся между кадрами или его состояние надо сохранить между пересозданиями. |
| `Trigger` | `UiElement` | `null` | Элемент-цель: клик по нему открывает подтверждение. |
| `Message` | `string` | `""` | Текст вопроса. Переносится по словам. |
| `Icon` | `int` | `Icons.Warning` | Иконка слева от сообщения (`-1` = без иконки). |
| `AcceptLabel` | `string` | `"OK"` | Подпись кнопки подтверждения. |
| `RejectLabel` | `string` | `"X"` | Подпись кнопки отказа. |
| `OnAccept` | `Action` | `null` | Подтверждено. |
| `OnReject` | `Action` | `null` | Отказ (кнопка «нет»). |
| `Placement` | `OverlayPlacement` | `Bottom` | Сторона раскрытия: `Bottom`, `Top`, `Right`, `Left`. |
| `Danger` | `bool` | `false` | Кнопка подтверждения красная (опасное действие). |
| `MaxMessageWidth` | `float` | `260` | Ширина, по которой переносится сообщение. |
| `Disabled` | `bool` | `false` | Отключённое состояние. |

## Поведение

**Построен на `Popover`.** Overlay-слой, позиционирование у якоря и закрытие по клику мимо решены
там: панель не обрезается родителем, зажимается в границах окна, а если с заявленной стороны места
не хватает — раскрывается с противоположной.

**Закрытие.** Панель закрывается кнопкой (любой из двух), кликом мимо, повторным кликом по цели
или программно — методом `Close()`.

**Отказ по клику мимо не вызывает `OnReject`.** `OnReject` — это осознанное «нет», нажатие кнопки;
клик мимо означает «передумал(а) отвечать» и не должен запускать логику отказа.

**Порядок кнопок.** Отказ слева, подтверждение справа — так подтверждение оказывается ближе к краю,
куда естественно тянется рука после чтения текста.

## Стили

Панель — это `Popover`, поэтому темизируется слотом `PopoverPanel` (фон, бордюр, радиус, отступы,
тень). Кнопки — обычные `Button`, слот `button`; красная кнопка при `Danger` берёт цвет из пресета
`ButtonPreset.Danger`.

## Методы

| Метод | Возвращает | Описание |
|---|---|---|
| `Close()` | — | Закрыть подтверждение программно — например, после того как действие выполнено асинхронно. Панель закроется на ближайшем кадре. |

## События

| Событие | Тип | Параметры | Когда вызывается |
|---|---|---|---|
| `OnAccept` | `Action` | — | Нажата кнопка подтверждения. |
| `OnReject` | `Action` | — | Нажата кнопка отказа (но не клик мимо). |
| `Events.HoverEnter` / `Events.HoverLeave` | `UiEventHandler` | `data.MousePosition` | Курсор вошёл/покинул границы **цели** (панель — вне потока). |
| `Events.Click` / `Events.RightClick` | `UiEventHandler` | `data.MousePosition` | ЛКМ / ПКМ по цели. |
| `Events.DisabledChanged` | `UiEventHandler` | `data.Disabled` | Смена `Disabled`. |

## Поддержка механик

| Механика | Поддержка | Пояснение |
|---|---|---|
| Стиль | Да | Через слот `PopoverPanel` и стили кнопок. |
| Спрайт-рамка | Да | Панель поддерживает 9-slice, как обычный `Popover`. |
| Анимация | Да | Общий механизм `Style.Animation`. |
| Disabled | Да | Кнопки внутри панели блокируются. |
| Hover-fade | Да | У кнопок внутри — обычный плавный hover кнопок. |
| Курсор | Да | Рука над целью и кнопками. |
