# Timeline

Лента событий: маркеры на оси, соединительные линии между ними, содержимое сбоку. Вертикальная
(события сверху вниз) и горизонтальная (слева направо) ориентации.

`RimUI.Components.Timeline : UiElement`

## Три полосы поперёк ленты

Поперёк ленты место делится на три полосы:

```
[ противоположная сторона ] [ ось с маркерами ] [ содержимое ]
```

«Противоположная сторона» — для даты, времени, статуса: короткой подписи, которая логически
относится к событию, но не является его содержимым. Если её не использует ни одно событие, полоса
не создаётся и место не тратится.

Сторону содержимого задаёт `Align`. При `Alternate` содержимое чередуется, и тогда обе полосы
получают **одинаковый размер** — иначе ось гуляла бы поперёк ленты от события к событию вслед за
содержимым.

## Пример

```csharp
var tl = new Timeline { OppositeSize = 90f };
tl.Items.Add(new TimelineItem("Высадка на планету", "День 1") { Icon = Icons.Check });
tl.Items.Add(new TimelineItem("Построено убежище", "День 3"));
tl.Items.Add(new TimelineItem("Первый рейд", "День 12") { MarkerColor = danger });

// чередование сторон
new Timeline { Align = TimelineAlign.Alternate };

// горизонтальная лента
new Timeline { Orientation = TimelineOrientation.Horizontal, MinItemExtent = 96f };

// произвольное содержимое вместо строки
tl.Items.Add(new TimelineItem { Content = myPanel, Opposite = "День 20" });
```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Items` | `List<TimelineItem>` (readonly) | пусто | События ленты. |
| `Orientation` | `TimelineOrientation` | `Vertical` | `Vertical` (сверху вниз) или `Horizontal` (слева направо). |
| `Align` | `TimelineAlign` | `End` | Сторона содержимого: `Start`, `End` или `Alternate`. |
| `MarkerSize` | `float` | `12` | Диаметр маркера. |
| `LineThickness` | `float` | `1` | Толщина соединительной линии. |
| `AxisSize` | `float` | `28` | Ширина полосы с маркерами. |
| `ItemGap` | `float` | `10` | Зазор между событиями вдоль ленты. |
| `OppositeSize` | `float` | `0` | Размер полосы противоположной стороны. `0` = автоматически. |
| `MinItemExtent` | `float` | `34` | Минимальный размер события вдоль ленты. |

### TimelineItem

| Поле | Тип | Описание |
|---|---|---|
| `Key` | `string` | Стабильный ключ события (`null` = индекс). |
| `Text` | `string` | Содержимое строкой (если не задан `Content`). |
| `Opposite` | `string` | Подпись противоположной стороны. |
| `Content` | `UiElement` | Произвольное содержимое (приоритетнее `Text`). |
| `OppositeContent` | `UiElement` | Произвольное содержимое противоположной стороны. |
| `Icon` | `int` | Иконка внутри маркера (индекс листа `Icons`; `-1` = без иконки). |
| `MarkerColor` | `ColorRGBA?` | Свой цвет маркера (`null` = цвет из темы). |
| `Value` | `object` | Полезная нагрузка. |

## Поведение

**Линия рисуется от маркера к маркеру**, поэтому у последнего события хвоста нет: лента
заканчивается ровно на нём, а не уходит в пустоту.

**Подписи прижимаются к оси**, а не к внешнему краю своей полосы: иначе между текстом и маркером
зияла бы пустота тем большая, чем шире полоса, и связь «подпись — маркер» терялась бы. В
горизонтальной ленте подписи центрируются под маркером — маркер стоит в середине отрезка события.
Это касается только подписей из строк; произвольный `Content` выравниваете вы.

**Размер поперёк ленты** берётся так же, как у прочих компонентов: явный `Style.Width` /
`Style.Height`, иначе предложенный родителем. Если родитель ось не ограничивает (например,
горизонтальная лента внутри колонки), полосы считаются **по содержимому** — иначе лента заняла бы
всю доступную высоту и под ней зияла бы пустота.

**`MinItemExtent`** не даёт событиям с коротким текстом слипнуться: без него линия между
маркерами почти исчезает.

## Стили

| Слот | Назначение |
|---|---|
| `timeline/marker` | Маркер: `Background` — заливка, `Text.Color` — цвет иконки внутри. |
| `timeline/line` | Цвет соединительной линии (берётся только цвет: линии рисуются командами, а не фоном). |

Цвет отдельного маркера перекрывается полем `TimelineItem.MarkerColor` — удобно для статусов
«сделано / в работе / впереди».

## Методы

Собственных методов нет: лента — представление, состояния у неё нет. Всё управление — через список
`Items` и поля события.

## События

| Событие | Тип | Параметры | Когда вызывается |
|---|---|---|---|
| `Events.HoverEnter` / `Events.HoverLeave` | `UiEventHandler` | `data.MousePosition` | Курсор вошёл/покинул границы ленты. |
| `Events.Hover` | `UiEventHandler` | `data.MousePosition` | Курсор над лентой — КАЖДЫЙ КАДР. |
| `Events.Click` / `Events.RightClick` | `UiEventHandler` | `data.MousePosition` | ЛКМ / ПКМ по ленте. |
| `Events.Scroll` | `UiEventHandler` | `data.ScrollDelta` | Колесо над лентой. |

Событий «по событию ленты» нет: если нужен клик по конкретному пункту, положите в `Content`
кликабельный элемент (например, `Button`) — он и получит своё событие.

## Поддержка механик

| Механика | Поддержка | Пояснение |
|---|---|---|
| Стиль | Да | Слоты маркера и линии, обычный `Style` самой ленты. |
| Спрайт-рамка | Да | Через слот `timeline/marker` и `Style` ленты. |
| Анимация | Да | Общий механизм `Style.Animation`. |
| Disabled | Нет | Лента не интерактивна; неактивность выражается содержимым. |
| Hover-fade | Нет | Собственных hover-состояний нет. |
| Курсор | Нет | Заявляют содержимое и вложенные элементы. |
