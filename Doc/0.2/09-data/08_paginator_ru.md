# Paginator

Постраничная навигация: стрелки «в начало / назад / вперёд / в конец», номера страниц с
многоточием и опциональный выбор размера страницы.

Компонент **не владеет данными**: он не знает, что и откуда выбирать, — его дело сообщить, какую
страницу запросил пользователь. Выборка (`Skip`/`Take`) остаётся у вас.

`RimUI.Components.Paginator : UiElement`

## Нумерация с единицы

Наружу (`Page`, `OnChange`, `GetPage`, `SetPage`) страницы считаются **с 1** — так, как их видит
пользователь на экране. Индексы с нуля удобнее при выборке, но тогда пришлось бы держать в голове,
что «страница 3» в обработчике — это четвёртая на экране; цена такой ошибки выше, чем экономия на
одном вычитании:

```csharp
int from = (page - 1) * pageSize;   // перевод в индекс делается один раз, у вас
```

## Пример

```csharp
var pager = new Paginator
{
    TotalItems = items.Count,
    PageSize = 10,
    Page = () => _page,
    OnChange = p => { _page = p; RebuildPage(); },
    SummaryText = (a, b, c) => a + "-" + b + " из " + c
};
pager.PageSizeOptions.Add(10);
pager.PageSizeOptions.Add(25);
pager.PageSizeOptions.Add(50);
pager.OnPageSizeChange = size => { _pageSize = size; RebuildPage(); };

// компактный вариант
new Paginator { TotalItems = 42, PageSize = 10, ShowFirstLast = false, VisiblePages = 3 };
```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Key` | `string` | `null` | Ключ состояния в ID-store (см. «Ключ и состояние» на странице «Архитектура»). Нужен, если элемент пересоздаётся между кадрами или его состояние надо сохранить между пересозданиями. |
| `TotalItems` | `int` | `0` | Всего элементов. Число страниц считается из него и `PageSize`. |
| `PageSize` | `int` | `10` | Элементов на странице. |
| `Page` | `Func<int>` | `null` | Источник текущей страницы (с 1). `null` = страница живёт в ID-store. |
| `OnChange` | `Action<int>` | `null` | Пользователь выбрал страницу. |
| `PageSizeOptions` | `List<int>` (readonly) | пусто | Варианты размера страницы. Пусто = выбор не показывается. |
| `OnPageSizeChange` | `Action<int>` | `null` | Пользователь сменил размер страницы. |
| `ShowFirstLast` | `bool` | `true` | Кнопки «в начало» и «в конец» (двойные шевроны). |
| `VisiblePages` | `int` | `5` | Сколько номеров показывать вокруг текущего (не считая первой и последней). |
| `SummaryText` | `Func<int,int,int,string>` | `null` | Подпись справа: аргументы `(первый, последний, всего)`. Текст задаёте вы — ядро языков не знает. |
| `ButtonSize` | `float` | `26` | Размер кнопки. |
| `ButtonGap` | `float` | `3` | Зазор между кнопками. |
| `PageSizeWidth` | `float` | `62` | Ширина поля выбора размера страницы. |
| `Disabled` | `bool` | `false` | Отключённое состояние. |

## Поведение

**Первая и последняя страницы видны всегда.** По ним чаще всего и прыгают, а многоточие лишь
сообщает, что между ними что-то пропущено. Окно номеров вокруг текущей страницы задаётся
`VisiblePages`.

**Смена размера страницы возвращает на первую.** Текущая страница почти всегда оказывается за
границами нового диапазона (было 20 страниц по 10, стало 4 по 50), и пользователь увидел бы пустоту.

**Страниц всегда хотя бы одна.** Пустой список — это одна пустая страница, а не ноль страниц:
иначе номер текущей оказался бы вне допустимого диапазона.

**Текущий номер не нажимается**, но и не выглядит отключённым: он выделяется акцентом. Отключённый
вид получают только стрелки на краях диапазона.

**`PageSizeWidth` фиксирован не от лени.** `Select` без явной ширины занимает всё предложенное
место, а предлагается ему ширина блока — поле уезжало бы за край. Вариантов там всегда два-три
коротких числа.

## Стили

| Слот | Назначение |
|---|---|
| `paginator/button` | Кнопка (номер или стрелка). |
| `paginator/button_hover` | Под курсором. |
| `paginator/button_active` | Текущая страница. |
| `paginator/button_disabled` | Недоступная кнопка (край диапазона). |
| `paginator/text` | Цвет номера. |
| `paginator/text_active` | Цвет номера текущей страницы. |
| `paginator/text_disabled` | Цвет недоступного номера и многоточия. |

Поле выбора размера страницы — обычный `Select<int>`, поэтому темизируется слотами `select/*`.

## Методы

| Метод | Возвращает | Описание |
|---|---|---|
| `PageCount` (свойство) | `int` | Всего страниц (минимум 1). |
| `GetPage()` | `int` | Текущая страница (с 1): источник `Page`, если задан, иначе кэш последнего кадра. |
| `SetPage(int page)` | — | Программно перейти на страницу: номер зажимается в диапазон и вызывает `OnChange`. |

## События

| Событие | Тип | Параметры | Когда вызывается |
|---|---|---|---|
| `OnChange` | `Action<int>` | номер страницы (с 1) | Клик по номеру или стрелке, а также смена размера страницы (переход на первую). |
| `OnPageSizeChange` | `Action<int>` | новый размер | Выбран другой размер страницы. |
| `Events.SelectionChanged` | `UiEventHandler` | `data.SelectedIndex`, `data.SelectedValue` | То же, что `OnChange`. Индекс — номер страницы **с нуля**, значение — номер с 1. |
| `Events.HoverEnter` / `Events.HoverLeave` | `UiEventHandler` | `data.MousePosition` | Курсор вошёл/покинул границы. |
| `Events.Click` / `Events.RightClick` | `UiEventHandler` | `data.MousePosition` | ЛКМ / ПКМ по элементу. |
| `Events.DisabledChanged` | `UiEventHandler` | `data.Disabled` | Смена `Disabled`. |

## Поддержка механик

| Механика | Поддержка | Пояснение |
|---|---|---|
| Стиль | Да | Слоты кнопок и текста, плюс обычный `Style` самого ряда. |
| Спрайт-рамка | Да | Через слот `paginator/button`. |
| Анимация | Да | Общий механизм `Style.Animation`. |
| Disabled | Да | Слот `paginator/button_disabled`, ввод блокируется. |
| Hover-fade | Нет | Состояние кнопки переключается мгновенно. |
| Курсор | Да | Рука над доступными кнопками. |
