# Stepper

Пошаговый мастер: полоса заголовков с индикатором пройденного, содержимое активного шага и кнопки
навигации. На последнем шаге «Далее» превращается в «Готово».

`RimUI.Components.Stepper : UiElement`

## Два режима

**Линейный** (по умолчанию) — идти можно только по порядку: вперёд на один шаг и назад по уже
пройденным. Произвольный прыжок вперёд запрещён, потому что мастер обычно собирает данные, и шаг
N+2 не имеет смысла без шага N+1.

**Свободный** (`Linear = false`) — клик по любому заголовку. Для мастеров, где шаги независимы:
разделы настроек, вкладки с прогрессом.

## Пример

```csharp
var wizard = new Stepper
{
    BackLabel = "Назад",
    NextLabel = "Далее",
    FinishLabel = "Готово",
    OnFinish = () => ApplySettings(),
    Style = { Height = 190f }
};

wizard.Steps.Add(new StepperItem("Начало", introPanel));
wizard.Steps.Add(new StepperItem("Имя", namePanel)
{
    CanLeave = () => !string.IsNullOrEmpty(_name)     // не отпустит дальше без имени
});
wizard.Steps.Add(new StepperItem("Итог", summaryPanel));

// свободный режим без кнопок
new Stepper { Linear = false, ShowNav = false };
```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Key` | `string` | `null` | Ключ состояния в ID-store (см. «Ключ и состояние» на странице «Архитектура»). Нужен, если элемент пересоздаётся между кадрами или его состояние надо сохранить между пересозданиями. |
| `Steps` | `List<StepperItem>` (readonly) | пусто | Шаги мастера. |
| `Active` | `Func<int>` | `null` | Источник активного шага (индекс **с 0**). `null` = шаг живёт в ID-store. |
| `OnChange` | `Action<int>` | `null` | Активный шаг изменился. |
| `OnFinish` | `Action` | `null` | Нажата «Готово» на последнем шаге. |
| `Linear` | `bool` | `true` | Только по порядку: прыжок вперёд через шаг запрещён. |
| `ShowNav` | `bool` | `true` | Кнопки «Назад» / «Далее» под содержимым. |
| `BackLabel`, `NextLabel`, `FinishLabel` | `string` | `"<"`, `">"`, `"OK"` | Подписи кнопок. Задаёте вы — ядро языков не знает. |
| `HeaderHeight` | `float` | `0` (авто) | Высота полосы заголовков. `0` = по самой высокой подписи при фактической ширине ячейки. |
| `MarkerSize` | `float` | `24` | Диаметр кружка шага. |
| `NavHeight` | `float` | `30` | Высота полосы кнопок. |
| `SectionGap` | `float` | `10` | Зазор между заголовками, содержимым и кнопками. |
| `Disabled` | `bool` | `false` | Отключённое состояние. |

### StepperItem

| Поле | Тип | Описание |
|---|---|---|
| `Title` | `string` | Подпись под кружком. Переносится по словам. |
| `Content` | `UiElement` | Содержимое шага. |
| `Icon` | `int` | Иконка вместо номера в кружке (`-1` = номер). |
| `Disabled` | `bool` | Шаг недоступен для клика. |
| `CanLeave` | `Func<bool>` | Можно ли уйти с шага **вперёд**. `null` = всегда можно. |

## Поведение

**Валидация только вперёд.** `CanLeave` проверяется при движении вперёд и при нажатии «Готово».
Назад пользователь должен уходить всегда, иначе незаполненная форма превращается в ловушку без
выхода.

**`SetActive` валидацию не применяет** — это команда кода, а не клик пользователя: мододел знает,
что делает.

**Пройденный шаг помечается галочкой**, а не номером: номер там уже не информация, а галочка сразу
отвечает на вопрос «что сделано». Своя иконка (`StepperItem.Icon`) перекрывает и то и другое.

**Коннектор между кружками** окрашен акцентом на пройденной части — видно не только «где я», но и
«сколько позади».

**Заголовки делят ширину поровну.** Тогда коннекторы одинаковой длины, и полоса не «дышит» при
переходе между шагами с разной длиной названия.

**Высота полосы заголовков считается автоматически** — по самой высокой подписи при фактической
ширине ячейки. Фиксированная высота обрезала бы длинные названия, которым нужен перенос на вторую
строку.

**До какого шага можно вернуться.** Компонент запоминает самый дальний достигнутый шаг: в линейном
режиме кликом можно перейти на любой уже пройденный, но не дальше.

## Стили

| Слот | Назначение |
|---|---|
| `stepper/marker` | Кружок будущего шага. |
| `stepper/marker_active` | Кружок текущего шага; `Text.Color` — цвет номера и галочки. |
| `stepper/marker_done` | Кружок пройденного шага. |
| `stepper/connector` | Цвет линии между кружками (берётся только цвет). |
| `stepper/connector_done` | Цвет пройденной части линии. |

Кнопки навигации — обычные `Button`, поэтому темизируются слотом `button`.

## Методы

| Метод | Возвращает | Описание |
|---|---|---|
| `GetActive()` | `int` | Индекс активного шага (с 0): источник `Active`, если задан, иначе кэш последнего кадра. |
| `SetActive(int index)` | — | Перейти на шаг программно, без проверки `Linear` и `CanLeave`. Вызывает `OnChange`. |

## События

| Событие | Тип | Параметры | Когда вызывается |
|---|---|---|---|
| `OnChange` | `Action<int>` | индекс шага (с 0) | Переход на другой шаг: клик по заголовку, кнопки, `SetActive`. |
| `OnFinish` | `Action` | — | «Готово» на последнем шаге (после успешной проверки `CanLeave`). |
| `Events.SelectionChanged` | `UiEventHandler` | `data.SelectedIndex`, `data.SelectedValue` | Смена шага кликом по заголовку; значение — сам `StepperItem`. |
| `Events.HoverEnter` / `Events.HoverLeave` | `UiEventHandler` | `data.MousePosition` | Курсор вошёл/покинул границы. |
| `Events.Click` / `Events.RightClick` | `UiEventHandler` | `data.MousePosition` | ЛКМ / ПКМ по компоненту. |
| `Events.DisabledChanged` | `UiEventHandler` | `data.Disabled` | Смена `Disabled`. |

## Поддержка механик

| Механика | Поддержка | Пояснение |
|---|---|---|
| Стиль | Да | Слоты маркеров и коннекторов, обычный `Style` компонента. |
| Спрайт-рамка | Да | Через слот `stepper/marker` и `Style` компонента. |
| Анимация | Да | Общий механизм `Style.Animation`. |
| Disabled | Да | Блокируются и заголовки, и кнопки навигации. |
| Hover-fade | Нет | Состояние шага переключается мгновенно. |
| Курсор | Да | Рука над заголовками, на которые можно перейти. |
