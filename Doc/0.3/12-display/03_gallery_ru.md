# Gallery

Галерея изображений: большой кадр по центру, стрелки по бокам переключают картинку, а внизу —
лента миниатюр для быстрого перехода к нужной; можно включить автоматическое перелистывание по
таймеру.

`RimUI.Components.Gallery : UiElement`

## Пример

```csharp
var g = new Gallery { Key = "gallery1", Style = { Width = 320f } };
g.Images.AddRange(new[] { "demo/photo1", "demo/photo2", "demo/photo3" });

var g2 = new Gallery { Key = "gallery2", AutoAdvance = 2.5f, ShowThumbnails = false,
    Style = { Width = 220f, Height = 140f } };
g2.Images.AddRange(new[] { "demo/photo1", "demo/photo2" });
```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Key` | `string` | `null` | Ключ состояния в ID-store (см. «Ключ и состояние» на странице «Архитектура»). Нужен, если элемент пересоздаётся между кадрами или его состояние надо сохранить между пересозданиями. |
| `Images` | `List<string>` | пусто | Ключи текстур. |
| `AutoAdvance` | `float` | `0` (выкл) | Автоперелистывание, сек; сбрасывается таймер при ручном переходе. |
| `FrameHeight` | `float` | `200` | Высота большого кадра. |
| `ThumbHeight` | `float` | `40` | Высота миниатюр. |
| `ShowCounter` | `bool` | `true` | Показывать «i из N». |
| `ShowThumbnails` | `bool` | `true` | Показывать ленту миниатюр. |
| `OnChange` | `Action<int>` | `null` | Колбэк при смене изображения (ручной переход или авто). |

**Важно:** внутреннее состояние (текущий индекс) хранится по `Key` — если галерей несколько на
экране, каждой нужен свой уникальный `Key`.

### Точная механика таймера `AutoAdvance`

Таймер не отсчитывает накопительно и не «обнуляется» в привычном смысле — хранится абсолютный
момент времени последнего перехода (`LastAdvance`), а следующий авто-переход наступает, когда
`ctx.Time - LastAdvance >= AutoAdvance`. **Любой** переход — и ручной (клик по стрелке/миниатюре),
и автоматический — идёт через один и тот же внутренний метод и одинаково переустанавливает
`LastAdvance` на текущий момент, поэтому ручной клик полностью перезапускает отсчёт до следующего
автоперелистывания на `AutoAdvance` секунд вперёд. Исключение: если клик пришёлся на уже
показанное изображение (например, повторный клик по активной миниатюре) — переход не
засчитывается, и таймер не сбрасывается. Отсчёт первого автоперелистывания идёт от момента
появления `Gallery` на экране (инициализация таймера при первом кадре), а не от абсолютного нуля.
Переключение изображений мгновенное — плавного fade-перехода между кадрами нет.

## Стили

Рамка кадра/миниатюр рисуется фиксированным стилем с цветом из палитры темы (`Theme.SurfaceAlt`/
`ControlBorder`/`ControlAccent`), без чтения `Sprite`-слотов.

## Методы

Явного публичного конструктора с параметрами нет — только `new Gallery { ... }` через
инициализатор полей.

| Метод | Возвращает | Описание |
|---|---|---|
| `GetSelected()` | `int` | Индекс текущего кадра: если только что вызывали `SetSelected` — вернёт его значение (применится на следующем кадре отрисовки), иначе — индекс, отрисованный в последнем кадре. До первого показа — `0`. |
| `SetSelected(int index)` | `void` | Программно перейти к кадру — как клик по стрелке/миниатюре: переход применяется на следующем отрисованном кадре и вызывает те же колбэки (`OnChange`, `Events.SelectionChanged`), что и обычное взаимодействие. Индекс **зацикливается**: `idx = ((idx % n) + n) % n`, то есть и отрицательные, и выходящие за `Images.Count` значения оборачиваются в допустимый диапазон (не клампятся). |
| `SetStyle(string path, string value)` | — | Установить поле стиля строкой (`"text.color"`, `"background"`, `"radius"` и т.д.). Именованных частей стиля (`StylePart`) у `Gallery` нет — путь применяется напрямую к стилю элемента; рамка кадра/миниатюр рисуется отдельным фиксированным стилем и `SetStyle` не затрагивается. Неизвестный путь/значение — тихо игнорируется. |

## События

| Событие | Тип | Параметры | Когда вызывается |
|---|---|---|---|
| `OnChange` | `Action<int>` | индекс нового изображения | Ручной переход (стрелки/миниатюра) или автоперелистывание. |
| `Events.SelectionChanged` | `UiEventHandler` | `data.SelectedIndex` (новый индекс), `data.SelectedValue` (ключ текстуры `Images[idx]`) | То же самое событие смены кадра, что и `OnChange`, но через универсальный механизм `UiElement.Events` — ручной переход, автоперелистывание или `SetSelected`. |
| `Events.HoverEnter` / `Events.HoverLeave` | `UiEventHandler` | `data.MousePosition` | Курсор вошёл/покинул границы (по разу на переход). |
| `Events.Hover` | `UiEventHandler` | `data.MousePosition` | Курсор над элементом — КАЖДЫЙ КАДР (~60 раз/сек). Обработчик должен быть лёгким: без аллокаций, поиска, IO — тяжёлая логика здесь просадит FPS. |
| `Events.Click` / `Events.RightClick` | `UiEventHandler` | `data.MousePosition` | ЛКМ / ПКМ по элементу (вне зависимости от клика по стрелкам/миниатюрам, которые обрабатываются отдельно). |
| `Events.Scroll` | `UiEventHandler` | `data.ScrollDelta` | Колесо мыши над элементом. |
| `Events.DisabledChanged` | `UiEventHandler` | `data.Disabled` | Изменилась эффективная активность. |

## Поддержка механик

| Механика | Поддержка | Пояснение |
|---|---|---|
| Стиль | Да | `Style.Width`/`Height`. |
| Спрайт-рамка | Нет | Рамка кадра/миниатюр рисуется фиксированным стилем из палитры темы, не спрайтом. |
| Анимация | Да | Общий механизм `Style.Animation` доступен базово; автоперелистывание — собственная логика по таймеру. |
| Disabled | Нет | Своего понятия «отключена» нет. |
| Hover-fade | Частично | Стрелки навигации меняют альфу подложки при наведении напрямую (булевы `hoverL`/`hoverR`), без плавного перехода через `HoverFade`. |

Полноэкранного просмотра/зума нет.
