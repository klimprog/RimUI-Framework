# Style — модель стиля

Каждый элемент (`UiElement`) имеет публичное поле `Style Style` — это данные, ничего не рисуют
сами по себе. Резолв (что взять из явно заданного стиля, а что добрать из темы) происходит на
каждом кадре, поэтому смена темы «на лету» подхватывается даже уже открытыми окнами. `null` у
большинства полей означает «не задано — взять из слота темы»; явные `Fill.Off`/`BoxShadow.Off`/
`BorderWidth.None` — осознанное отключение, обрывающее цепочку приоритетов.

`RimUI.Styling.Style` (sealed class)

## Пример

```csharp
el.Style.Margin = new Thickness(8f);
el.Style.Padding = new Thickness(12f, 8f);
el.Style.Width = 200f;                 // 0 = авто (по контенту/долям сетки)
el.Style.Background = Fill.Solid(new ColorRGBA(0.2f, 0.3f, 0.5f, 1f));
el.Style.Radius = BorderRadius.Middle;
el.Style.BorderWidth = BorderWidth.Small;
el.Style.BorderColor = ColorRGBA.White.WithAlpha(0.4f);
el.Style.Shadow = new BoxShadow { Offset = new Vec2(0, 2), Blur = 8f, Color = new ColorRGBA(0, 0, 0, 0.45f) };
el.Style.Text = new TextStyle { Align = TextAlign.Center, Color = ColorRGBA.White };
```

## Курсор

`Style.Cursor` задаёт **смысл** курсора, а конкретную текстуру и точку клика подставляет тема
(`Theme.Cursors`). Виды:

| Значение | Смысл |
|---|---|
| `None` | Не заявлять курсор: элемент прозрачен для этого механизма (значение по умолчанию задаётся как `null`). |
| `Arrow` | Явная стрелка. Не то же самое, что `None`: `Arrow` **отменяет** курсор родителя. |
| `Hand` | Кликабельное: кнопки, шапка окна, пункты меню. |
| `Move` | Перетаскивание (системный SIZEALL). |
| `Text` | Ввод текста. |
| `ResizeH`, `ResizeV`, `ResizeNWSE`, `ResizeNESW` | Изменение размера по горизонтали, вертикали и двум диагоналям. |

Как это работает: каждый элемент под мышью заявляет свой курсор, **побеждает самый глубокий**, и
вид применяется один раз за кадр. Неактивные элементы (`EffectiveDisabled`) курсор не заявляют —
рука над недоступной кнопкой соврала бы.

По умолчанию из темы приходят: рука для кнопок (`button`) и поля выбора (`select/field`), каретка
для поля ввода (`input/frame`), рука для шапки перетаскиваемого окна. Отключить можно темой:

```json
{ "button": { "cursor": "none" } }
```

Значения для JSON-темы: `none`, `arrow`, `hand`, `move`, `text`, `resize-h`, `resize-v`,
`resize-nwse`, `resize-nesw`.

> Курсоры ОС модам недоступны: Unity в рантайме умеет только `SetCursor(текстура, hotspot)`, а
> именованные системные курсоры живут в редакторе. Поэтому фреймворк везёт свои ассеты,
> нарисованные в системном стиле — белое тело с чёрным контуром. Заменить их можно, подменив
> записи в `Theme.Cursors`.

## Границы размера

`MinWidth`/`MaxWidth`/`MinHeight`/`MaxHeight` задают диапазон, в который обязан уложиться
итоговый размер. Ноль означает «не задано», поэтому границу нельзя выключить нулём — она просто
не действует.

Работают они в обоих случаях: и когда размер вычисляется по содержимому (сначала считается
контент, потом зажимается), и когда задан явно — явный размер тоже обязан уложиться в диапазон.
При конфликте побеждает минимум: `Width = 200`, `MaxWidth = 90`, `MinWidth = 120` дадут 120.

Кратность 3 к границам **не применяется**: это границы диапазона, а не модуль декора, и
округление сдвигало бы предел не туда.

```csharp
// Панель не уже 200 и не шире 400, высота растёт по содержимому, но не выше 300.
var p = new Panel { Style = { MinWidth = 200f, MaxWidth = 400f, MaxHeight = 300f } };
```

Содержимое, которому не дали расти, по умолчанию выходит за границу: чтобы оно не налезало на
соседей, задайте `OverflowY = Overflow.Clip` (обрезка) или заверните блок в `ScrollBox`.

## Перенос детей (`WrapChildren`)

Контейнер с `WrapChildren = true` переносит не поместившихся детей на новую строку. Каждая
строка раскладывается **самостоятельно**: `Grow` растягивает элементы внутри своей строки, а
`JustifyContent` распределяет их там же. Иначе растяжение съело бы весь контейнер и перенос
потерял бы смысл.

Первый элемент строки не переносится, даже если он сам шире строки: иначе строка осталась бы
пустой, а элемент всё равно оказался бы в следующей — и так по кругу.

Перенос поддерживают и компоненты-ряды: `SelectButton`, `Paginator`, `Stepper`, `Tabs`,
`Gallery`.

```csharp
var chips = new FlexBox(Axis.Row) { Style = { Gap = 6f, WrapChildren = true, Width = 300f } };
```

## Сжатие (`Shrink`)

Когда дети не помещаются, контейнер ужимает их пропорционально размеру и весу `Shrink` — как
`flex-shrink` в CSS. `Shrink = 0` означает «меня не сжимать»: элемент сохраняет свой размер, а
недостаток места разбирают остальные.

Это важно там, где блоку задана фиксированная высота, а содержимого больше: без `Shrink = 0`
дети ужимались бы все подряд и текст налезал на текст. Если несжимаемы **все**, содержимое честно
выходит за границу, и дальше им распоряжается `Overflow`.

## Порядок среди братьев (`ZOrder`)

`ZOrder` решает, кто из **братьев** первым получает клик, колесо и право заявить курсор, когда
элементы одного родителя перекрываются: в `Stack`, у декора поверх содержимого, у оверлеев.
Больше — важнее. На порядок **отрисовки** свойство не влияет: старший по-прежнему рисуется
поверх, как и раньше.

Глубина учитывается сама собой — ребёнок всегда важнее предка, и задавать для этого `ZOrder` не
нужно.

Клик достаётся ровно одному элементу: первый обработавший забирает его себе. То же и с колесом —
прокрутка достаётся тому, кто под курсором, и не «проваливается» в список под ним.

## Растягивание мышью (`Resizable`)

`Style.Resizable` включает растягивание блока мышью. Тип — флаговое перечисление `ResizeEdges`:

| Значение | Что включает |
|---|---|
| `None` | Растягивания нет (по умолчанию). |
| `Left`, `Right`, `Top`, `Bottom` | Отдельная сторона. |
| `TopLeft`, `TopRight`, `BottomLeft`, `BottomRight` | Отдельный угол. |
| `Horizontal` | `Left \| Right`. |
| `Vertical` | `Top \| Bottom`. |
| `Corners` | Все четыре угла. |
| `All` | Стороны и углы — обычный набор. |

Флаги комбинируются: `ResizeEdges.Right | ResizeEdges.BottomRight`.

```csharp
var panel = new Panel
{
    Key = "myPanel",                       // см. ловушку про ключ ниже
    Style =
    {
        Width = 300f, Height = 200f,
        MinWidth = 120f, MaxWidth = 600f, MinHeight = 80f, MaxHeight = 400f,
        BorderWidth = BorderWidth.Small,   // без бордюра растягивания не будет
        Resizable = ResizeEdges.All,
    },
};
```

**Нет бордюра — нет растягивания.** Зона захвата — сама рамка блока. Если бордюр не задан,
захвата нет вовсе: тянуть за невидимую границу неочевидно, человек не догадается, где она.
Хотите растягиваемый блок — задайте бордюр, хотя бы однопиксельный.

Что происходит при растягивании:

* меняются **только** `Style.Width`/`Style.Height` в пределах `Min*`/`Max*`. Дальше раскладка,
  отступы, спрайт-рамка и вложенные элементы пересчитываются сами;
* тянем за рамку, а не за полосу внутри блока, поэтому содержимое остаётся полностью рабочим:
  кнопка у края и скроллбар кликаются как обычно;
* угол важнее стороны — угловая зона перекрывает две боковых, иначе по диагонали не потянуть;
* размер округляется к кратному 3 **вниз**, чтобы не выйти за предел, в который он упёрся.

**Родитель старше ребёнка.** По оси, размер которой вычисляет раскладка, растягивания нет —
курсор там не появляется, и мододел сразу видит, что тянуть нечего, вместо «тяну, а ничего не
происходит»:

| Ситуация | Кто распоряжается размером | Растягивание по оси |
|---|---|---|
| `Grow > 0` по главной оси `FlexBox` | Родитель доливает долю свободного места | нет |
| `AlignItems.Stretch` по поперечной оси | Родитель задаёт весь поперечник | нет |
| Ячейка `Grid` (и её содержимое) | Родитель: ширина от колонки, высота от строки | нет |
| Блок в обычном потоке без `Grow` | Сам блок | да |

Проверка выполняется в момент захвата, а не при установке флага: раскладка может измениться
между кадрами, и ответ должен быть свежим. Угол требует обе оси свободными — если одна занята
родителем, захват откатывается на сторону по свободной оси.

**Границы родителя нерушимы.** Дочерний блок не может растянуться дальше родителя и тем более
повлиять на его размер: у края растягивание упирается. Курсор при этом остаётся — тянуть можно,
просто дальше не растёт.

**Ловушка: нужен явный `Key`.** Растянутый размер — это состояние, а не поле объекта. Оно живёт
в ID-store и находится по ключу элемента. Если блок **пересоздаётся** (новый объект на каждом
кадре или при каждом открытии), автоключ меняется вместе с ним и размер теряется. Задайте
`Key` — та же ловушка, что у полей ввода.

## Кратность 3 (для `Width`/`Height`)

Явно заданные `Width`/`Height` округляются к ближайшему кратному 3 единицам. Причина —
декоративный модуль спрайт-тайлинга: 3 единицы = 12px на текстуре, и при тайлинге грани/фон
размножаются целыми плитками без обрезки декора. Отступы (`Margin`/`Padding`) кратности не
подчиняются. Округление — `Math.Round(v/3, MidpointRounding.AwayFromZero) * 3`:

| Вход | Результат |
|---|---|
| 1 | 0 |
| 2 | 3 |
| 28 | 27 |
| 29 | 30 |
| 30 | 30 |
| 31 | 30 |

**Важная ловушка**: `Width = 0` трактуется системой как «не задано / авто» (см. ниже про
`StyleMerge`). Любое значение из диапазона `(0, 1.5)` округляется в `0` и потому НЕЗАМЕТНО
превращается в авто-ширину, а не в маленький явный размер — например `Style.Width = 1f`
фактически будет проигнорирован. Порог переключения — `1.5`: при `v/3 = 0.5` округление
`AwayFromZero` даёт `1` → результат `3`; при `v` чуть меньше `1.5` результат `0`.

## Точный порядок резолва (StyleMerge)

Итоговый стиль элемента на каждом кадре собирается из двух явных слоёв: **код элемента** (`Style`)
поверх **слота темы** (уже включающего в себя приоритет «файл темы поверх зашитых дефолтов» —
это заложено ещё на этапе загрузки темы, до того как элемент вообще видит слот). Правило «что
считается незаданным» зависит от типа поля:

- Ссылочные/`nullable` поля (`Background`, `Radius`, `BorderWidth`, `BorderColor`, `BorderFill`)
  — обычное `own ?? слот`.
- `Text` (`TextStyle`) мержится ЦЕЛИКОМ ОБЪЕКТОМ, не по отдельным полям — если у элемента задан
  свой `Style.Text`, весь `TextStyle` слота (размер, выравнивание, шрифт, тень…) отбрасывается
  разом, а не мержится точечно.
- `Width`/`Height` — «не задано» = `0` (см. ловушку выше).
- `Margin`/`Padding` — любая ОТРИЦАТЕЛЬНАЯ компонента = явный `Off` (обрывает цепочку в ноль);
  любая НЕНУЛЕВАЯ компонента = «задано» (берём `own`); все нули — проваливаемся в слот.
- `AlignItems`/`JustifyContent` — «не задано» определяется сравнением с ДЕФОЛТНЫМ значением
  enum'а (`Stretch`/`Start`). Следствие: **нельзя явно задать `AlignItems.Stretch` или
  `JustifyContent.Start`, чтобы переопределить непустой слот темы** — такое значение неотличимо
  от «не задано» и всё равно провалится на слот.
- `Gap` — отрицательное значение = явный `Off` → `0`; положительное — берём `own`; ноль —
  проваливаемся в слот.
- `Animation` — `own ?? слот`, но **пустая строка `""` — не `null`**, поэтому явно перекрывает и
  выключает анимацию слота (в JSON темы это соответствует значению `"off"`).
- Позиционирование (`Left/Top/Right/Bottom/Anchor`) и переполнение (`OverflowX/OverflowY`) —
  берутся ТОЛЬКО из кода элемента, тема на них не влияет вообще (в JSON темы не поддерживаются).
- `AlignSelf` в общем механизме резолва не участвует вовсе — читается напрямую из сырого
  `Style` ребёнка внутри `FlexBox` (см. страницу «FlexBox»), слот темы задать его не может.

## Стили

Это и есть модель стилей — страница описывает саму себя. Слоты темы для конкретных компонентов
перечислены на страницах этих компонентов.

## Методы

| Метод | Возвращает | Описание |
|---|---|---|
| `Clone()` | `Style` | Глубокая копия (включая вложенный `Text`). |
| `static SnapUnit(float v)` | `float` | Округление размера к ближайшему кратному 3 (0/отрицательное = не трогать). |
| `SetExactSize(float w, float h)` | `void` | Служебная установка ТОЧНОГО размера без кратности 3 — для вычисленных размеров раскладки (зоны окон, панели оверлеев), где округление дало бы зазор/налезание. |
| `HasVisualBackground` (свойство) | `bool` | Есть ли видимый фон (для отрисовки). |
| `HasVisualBorder` (свойство) | `bool` | Есть ли видимая рамка. |

## События

Не применимо — `Style` это данные, не интерактивный элемент.

## Поддержка механик

| Механика | Поддержка | Пояснение |
|---|---|---|
| Слоты темы | Да | Всё, что не задано явно (`null`), добирается из слота темы компонента. |
