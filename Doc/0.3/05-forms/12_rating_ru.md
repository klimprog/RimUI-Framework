# Rating

Звёздочный рейтинг: оценка задаётся кликом по звезде. Значение **дробное** (`float`), а не номер
звезды — так выражаются половинки и внешние оценки вроде «4.2 из 5», которые надо показать, но не
обязательно вводить кликом.

`RimUI.Components.Rating : UiElement`

## Пример

```csharp
// Значение живёт у вас: делегат читается каждый кадр, копию обновлять не нужно
new Rating { Value = () => settings.Score, OnChange = v => settings.Score = v };

new Rating { AllowHalf = true };                       // клик в левую половину звезды даёт .5
new Rating { Stars = 10, StarSize = 14f };             // десять звёзд поменьше
new Rating { ReadOnly = true, Value = () => 4.5f };    // только показ, мышь игнорируется
```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Key` | `string` | `null` | Ключ состояния в ID-store (см. «Ключ и состояние» на странице «Архитектура»). Нужен, если элемент пересоздаётся между кадрами или его состояние надо сохранить между пересозданиями. |
| `Stars` | `int` | `5` | Количество звёзд, оно же максимум значения. |
| `Value` | `Func<float>` | `null` | Источник значения. `null` = значение живёт в ID-store компонента. |
| `OnChange` | `Action<float>` | `null` | Колбэк выбора оценки. |
| `ReadOnly` | `bool` | `false` | Только показ: мышь игнорируется, вид остаётся обычным. |
| `Disabled` | `bool` | `false` | Отключено: мышь игнорируется, звёзды приглушены. |
| `AllowHalf` | `bool` | `false` | Половинные значения: клик в левую половину звезды даёт `.5`. |
| `Cancel` | `bool` | `true` | Повторный клик по текущей оценке снимает её (значение `0`). |
| `StarSize` | `float` | `18` | Размер звезды. |
| `StarGap` | `float` | `3` | Зазор между звёздами. |

## Поведение

**Предпросмотр под курсором.** Пока мышь над рядом, звёзды показывают ту оценку, которую поставит
клик, а не текущее значение. Значение под курсором вычисляется до отрисовки — иначе первые звёзды
рисовались бы старым значением, а последние уже новым.

**Отмена оценки.** Без `Cancel` выставленную единицу нельзя было бы сбросить вовсе: слева от
первой звезды кликать некуда. Повторный клик по текущему значению даёт `0`.

**Зазор между звёздами** относится к левой звезде: клик ровно между двумя звёздами срабатывает,
а не проваливается в пустоту.

**Разница `ReadOnly` и `Disabled`.** `ReadOnly` — «оценка чужая, менять нечего»: вид обычный,
цвета не меняются. `Disabled` — «сейчас недоступно»: звёзды приглушены цветом
`rating/star_disabled`. Оба игнорируют мышь.

## Иконки

Звёзды берутся из общего листа иконок: `Icons.StarFull`, `Icons.StarEmpty`, `Icons.StarHalf`
(ячейки 19–21). Заменить рисунок можно, подменив лист — компонент трогать не нужно, см. страницу
про `Icons`.

## Стили

Слоты темы отдают компоненту **только цвет** (`Text.Color`): звёзды рисуются иконками с
тонированием, поэтому остальные поля стиля в этих слотах ни на что не влияют.

| Слот | Назначение |
|---|---|
| `rating/star` | Незаполненная звезда. |
| `rating/star_on` | Заполненная звезда. |
| `rating/star_hover` | Заполненная звезда во время предпросмотра под курсором. |
| `rating/star_disabled` | Все звёзды при `Disabled`. |

## Методы

| Метод | Возвращает | Описание |
|---|---|---|
| `GetValue()` | `float` | Текущая оценка: источник `Value`, если задан, иначе кэш последнего отрисованного кадра. |
| `SetValue(float v)` | — | Программно выставить оценку: значение зажимается в `0..Stars` и вызывает `OnChange`. Эффект — на ближайшем кадре. |

## События

| Событие | Тип | Параметры | Когда вызывается |
|---|---|---|---|
| `OnChange` | `Action<float>` | новая оценка | Клик по звезде (в том числе отмена — значение `0`). |
| `Events.SelectionChanged` | `UiEventHandler` | `data.SelectedIndex`, `data.SelectedValue` | То же событие в общем виде: индекс — номер звезды с нуля, значение — дробная оценка. |
| `Events.HoverEnter` / `Events.HoverLeave` | `UiEventHandler` | `data.MousePosition` | Курсор вошёл/покинул границы. |
| `Events.Hover` | `UiEventHandler` | `data.MousePosition` | Курсор над элементом — КАЖДЫЙ КАДР. |
| `Events.Click` / `Events.RightClick` | `UiEventHandler` | `data.MousePosition` | ЛКМ / ПКМ по элементу. |
| `Events.DisabledChanged` | `UiEventHandler` | `data.Disabled` | Смена `Disabled` (компонент переопределяет `EffectiveDisabled`). |

## Поддержка механик

| Механика | Поддержка | Пояснение |
|---|---|---|
| Стиль | Частично | Через слоты берётся цвет звёзд; фон и бордюр самого ряда — обычным `Style`. |
| Спрайт-рамка | Нет | Звёзды — иконки листа, не 9-slice. |
| Анимация | Да | Общий механизм `Style.Animation`. |
| Disabled | Да | Слот `rating/star_disabled`, ввод блокируется. |
| Hover-fade | Нет | Предпросмотр переключается мгновенно: плавность здесь мешала бы попасть в нужную звезду. |
| Курсор | Да | Рука над рядом, когда компонент интерактивен. |
