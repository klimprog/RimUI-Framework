# GridCell

Обёртка над содержимым одной ячейки сетки `Grid`: определяет, сколько колонок и строк занимает
контент. Умеет быть зоной drag&drop-«слота» — контент можно перетаскивать между ячейками мышью.

`RimUI.Layout.GridCell : UiElement`

## Пример

```csharp
var cell = new GridCell(4, rowSpan: 2).With(someContent);
grid.Cell(cell);

// drag&drop: два слота одной группы, дроп в занятый слот меняет элементы местами
var slotA = new GridCell(4) { DragGroup = "inventory" }.With(itemA);
var slotB = new GridCell(4) { DragGroup = "inventory" };   // пустой слот тоже участвует
```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `ColSpan` | `int` | `12` | Сколько из 12 колонок занимает ячейка (клампится в 1..12). |
| `RowSpan` | `int` | `1` | Сколько строк объединяет ячейка по вертикали. |
| `Content` | `UiElement` | `null` | Содержимое ячейки. |
| `DragGroup` | `string` | `null` | Идентификатор группы drag&drop; `null` = перетаскивание выключено. |
| `DragOut` | `bool` | `true` | Можно ли утащить контент ИЗ этой ячейки. |
| `DropIn` | `bool` | `true` | Принимает ли ячейка дроп (занятый слот — обмен местами). |
| `DragCopy` | `bool` | `false` | Источник отдаёт КОПИЮ вместо переноса (нужна `CopyOf`, иначе тихий откат к переносу). |
| `CopyOf` | `Func<UiElement, UiElement>` | `null` | Фабрика клона для `DragCopy`. |

## Стили

Обычный `Style` (фон/бордюр/паддинг), высота ячейки считается по контенту (или `Style.Height`,
если задан явно — задавать вручную обычно не требуется).

## Методы

| Метод | Возвращает | Описание |
|---|---|---|
| `GridCell(int colSpan = 12, int rowSpan = 1)` (конструктор) | — | Создать ячейку с заданной шириной/объединением. |
| `With(UiElement content)` | `GridCell` | Задать содержимое, возвращает себя (цепочка). |
| `SetContent(UiElement content)` | `void` | Сменить содержимое (используется и drag&drop-обменом). |

**Точный порог начала перетаскивания** — квадрат смещения мыши от точки нажатия должен превысить
25 (в единицах², то есть `dx² + dy² > 25`), это ровно **5 единиц** смещения. Пока порог не
пройден, событие остаётся обычным кликом и штатно обрабатывается кликабельным содержимым ячейки
(кнопки и т.п. продолжают работать) — драг-сессия не создаётся, пока курсор не сдвинулся
достаточно далеко.

## События

| Событие | Тип | Параметры | Когда вызывается |
|---|---|---|---|
| `OnDragStart` | `Action<UiElement>` | перетаскиваемый элемент | Контент взяли из ячейки (порог сдвига мыши пройден). |
| `OnDragOut` | `Action<UiElement>` | перетаскиваемый элемент | Контент утащили ИЗ ячейки (после изъятия при переносе). |
| `OnDropIn` | `Action<UiElement>` | принятый элемент | Элемент принят ячейкой (после установки `Content`). |

## Поддержка механик

| Механика | Поддержка | Пояснение |
|---|---|---|
| Стиль (`Style`) | Да | Фон/бордюр/скругление/тень как у любого элемента. |
| Спрайт-рамка | Да | Через `Style.Sprite`. |
| Анимация (`Style.Animation`) | Да | Общий механизм. |
| Disabled | Нет | Своего понятия «отключена» нет. |
| Hover-fade | Нет | Подсветка совместимого слота при drag — мгновенная, не плавная. |
| Drag&drop | Да | Ячейка-**слот**: один элемент; дроп в занятый слот меняет элементы местами. |
