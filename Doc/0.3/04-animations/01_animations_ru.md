# Animations — реестр модулей

Реестр модулей анимации: встроенные модули плюс возможность зарегистрировать свои. Immediate-mode
рендеринг делает анимацию «бесплатной» — элемент перерисовывается каждый кадр, а эффекты
(смещение, масштаб, прозрачность) применяются поверх уже нарисованных команд. Модуль подключается
либо обёрткой `Animated` (см. страницу «Animated»), либо строкой в `Style.Animation`/теме (см.
страницу «StyleAnimation»).

`RimUI.Animation.Animations` (static class)

## Пример

```csharp
using RimUI.Animation;

public sealed class MyBounce : IUiAnimation
{
    public void Apply(ref AnimFx fx, float k, AnimSpec spec)
    {
        float amp = spec.Param > 0f ? spec.Param : 8f;
        fx.Dy -= amp * Mathf.Sin(k * Mathf.PI);   // мутируем fx - аккумулируется с другими модулями
    }
}

Animations.Register("my-bounce", new MyBounce());
// дальше используется как встроенный: Animated.Wrap(el, "my-bounce", 0.5f)
// или Style.Animation = "my-bounce 0.5"
```

## Параметры — встроенные модули

| Имя | Поведение | Тип | `Param` по умолчанию |
|---|---|---|---|
| `fade-in` | появление (прозрачность 0→1) | one-shot | — |
| `fade-out` | исчезание (прозрачность 1→0) | one-shot | — |
| `pulse` | пульсация масштаба ±amp | loop | амплитуда = 0.05 (±5%) |
| `blink` | мигание прозрачностью («тревога») | loop | глубина = 0.45 |
| `slide-in-left` | въезд слева + появление | one-shot | дистанция = 24 ед |
| `slide-in-top` | въезд сверху + появление | one-shot | дистанция = 16 ед |
| `shake` | тряска с затуханием (ошибка ввода) | one-shot | амплитуда = 4 ед |
| `fade-in-up` | въезд снизу + появление (мягче `slide-in-top`, для мелких элементов) | one-shot | дистанция = 12 ед |
| `pop` | масштаб с небольшим перелётом (overshoot) | one-shot | старт-масштаб = 0.8 |
| `flash` | одиночная вспышка прозрачности (`Loop=true` — мигает повторно) | one-shot/loop | глубина = 0.7 |

`AnimSpec` (параметры экземпляра анимации на элементе): `string Name`, `float Duration = 0.3f`
(сек; для `Loop` — период), `bool Loop`, `float Delay` (задержка старта, сек), `float Param`
(модуле-специфичный параметр; 0 = дефолт модуля).

`AnimFx` (эффекты кадра, аккумулируются всеми активными анимациями элемента): `float Dx, Dy`
(смещение в единицах), `float Scale` (масштаб вокруг центра элемента, 1 = без изменений), `float
Opacity` (множитель прозрачности, 1 = непрозрачно).

### Точные формулы встроенных модулей

Общая механика фазы: `k = loop ? (t/dur) % 1 : min(t/dur, 1)`, где `t = ctx.Time - started -
delay` (клампится к 0, если анимация ещё не должна была начаться). `dur` не может быть меньше
`0.001` (защита от деления на ноль) — при очень малой длительности one-shot почти мгновенно
прыгает к `k=1`, а loop крутится с очень высокой частотой.

| Модуль | Формула |
|---|---|
| `fade-in` | `Opacity *= 1 - (1-k)²` |
| `fade-out` | `Opacity *= 1 - k²` |
| `pulse` | `Scale *= 1 + amp·sin(k·2π)` — частота колебания фиксирована (один полный цикл за `Duration`), `amp` (Param) на неё не влияет, только на размах. |
| `blink` | `Opacity *= 1 - depth·0.5·(1 + sin(k·2π))` — колебание в диапазоне `[1-depth, 1]`. |
| `flash` | `Opacity *= 1 - depth·sin(k·π)` — заметьте: частота `π`, не `2π`, как у `blink`: при `k=0` и `k=1` полностью непрозрачно, провал ровно на середине (`k=0.5`). |
| `shake` | `Dx += amp·(1-k)·sin(k·8π)` — частота `8π` даёт 4 полных колебания за длительность, амплитуда линейно затухает к нулю по мере роста `k`. |
| `slide-in-left`/`slide-in-top`/`fade-in-up` | смещение `d·(1-easeOut(k))` по соответствующей оси + `Opacity *= easeOut(k)`. |
| `pop` | easeOutBack: `x=k-1; back=1 + c3·x³ + c1·x²` при `c1=1.70158, c3=2.70158` (стандартные константы easing, дающие ровно 10% перелёта); `Scale *= from + (1-from)·back` — при `k→1` `Scale` сходится точно к 1.0, без остаточного смещения. Дополнительно `Opacity *= easeOut(k)` — `pop` всегда чуть прозрачен в начале анимации, это легко упустить, ориентируясь только на формулу масштаба. |

Модули `pulse`/`blink`/`flash`/`shake` управляют ЧИСЛОМ колебаний внутри цикла зашитой в код
частотой — `Duration` меняет длительность всего цикла целиком, а не частоту/число колебаний
внутри него.

## Стили

Не применимо напрямую — реестр работает поверх `Style.Animation`/`Animated`, не имеет
собственного визуального стиля.

## Методы

| Метод | Возвращает | Описание |
|---|---|---|
| `static Register(string name, IUiAnimation anim)` | `void` | Зарегистрировать модуль; пользовательский **перекрывает** встроенный с тем же именем. |
| `static Get(string name)` | `IUiAnimation` | Получить модуль по имени (или `null`). |
| `static EaseOut(float k)` | `float` | Хелпер сглаживания для своих модулей. |
| `static EaseIn(float k)` | `float` | Хелпер сглаживания. |
| `static EaseInOut(float k)` | `float` | Хелпер сглаживания. |

`IUiAnimation.Apply(ref AnimFx fx, float k, AnimSpec spec)` — контракт модуля: `k` — нормализованная
фаза 0..1 (one-shot: клампится и «замирает» на 1; loop: пила). Модуль мутирует `fx`.

## События

Не применимо — модули анимации не имеют колбэков, они читаются пассивно каждый кадр.

## Поддержка механик

| Механика | Поддержка | Пояснение |
|---|---|---|
| Свои модули | Да | `Animations.Register(name, module)`. |
| Подключение кодом | Да | Через обёртку `Animated` (см. отдельную страницу). |
| Подключение строкой | Да | Через `Style.Animation`/JSON темы (см. страницу «StyleAnimation»). |
| Вращение | Нет | Доступно только у `Icon.Rotation`, в `AnimFx` не входит. |
| Overlay-слои детей | Нет | Выпадающие панели/меню/тултипы не анимируются вместе с элементом. |
