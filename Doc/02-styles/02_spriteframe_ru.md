# SpriteFrame — спрайт-рамка и тайлинг

Спрайт-рамка (9-slice): рамка элемента рисуется из атласа вместо тонированных белых шаблонов.
Назначается через поле `Style.Sprite`; при заданном `Sprite` фон/бордюр/скругление/градиент из
этого же `Style` игнорируются (спрайт замещает их полностью, не комбинируется).

`RimUI.Styling.SpriteFrame` (sealed class)

## Формат текстуры-атласа

Один атлас — это ОДНА картинка, сетка **3×3 плитки** (4 угла + 4 грани + центр — 9 отдельных
под-спрайтов), между соседними плитками — **1 пиксель полностью прозрачных (альфа = 0)
пикселей-разделителей**. Без этого разрыва билинейная фильтрация Unity подтягивает цвет соседней
плитки на стык, и на границах появляется размытая кайма.

**Требования к картинке:**

| Требование | Значение | Обязательность |
|---|---|---|
| Форма листа | Квадрат (ширина = высота) | Жёсткое, хотя явно не проверяется кодом — размер плитки `T` считается ТОЛЬКО из ширины и применяется к обеим осям одинаково; если высота другая, вертикальные плитки съедут или обрежутся. |
| Сторона листа | `3·T + 2`, где `T` — сторона одной плитки в пикселях | Формула фиксированная. |
| Размер плитки `T` | Кратен 4 | Рекомендация, не проверяется — при некратном T кромка в единицах будет не целым числом пикселей. |
| Разрыв между плитками | Ровно 1px, альфа = 0 | Обязательно — иначе видна размытая кайма на стыках. |
| Все 9 плиток | Одного размера `T×T` | Обязательно — единая формула для строк и колонок. |

**Единицы измерения.** Все размеры рамки (`Edge`, `Reserve`) задаются в «единицах» фреймворка, не
в пикселях текстуры напрямую: **1 единица = 4 пикселя на текстуре**. Например, плитка `T = 48px`
вмещает `48 / 4 = 12` единиц — это максимум, который можно вырезать под угол/грань с одной
стороны (см. ограничение ниже).

**Пример реального атласа из комплекта** — `RimUI Framework/RimUIThemes/Default/assets/
demo/pattern.png`, **146×146 px**. Проверка формулы: `T = (146 − 2) / 3 = 48` px — целое число,
кратное 4. Между плитками (границы на x/y = 48 и 97) — столбец/строка полностью прозрачных
пикселей, как требуется.

## Как рамка вырезается из атласа

```csharp
el.Style.Sprite = new SpriteFrame("demo/pattern", 3f);
```

`SpriteFrame(atlasKey, corner: 3f)` даёт `Edge = 1`, `Reserve = 2`. Итоговый размер кромки по
стороне — `N = Edge + Reserve = 3` единицы = `3 × 4 = 12` пикселей.

1. `N` (в единицах) ограничивается сверху величиной `T / 4` (в единицах) — угол физически не
   может занимать больше, чем целая плитка листа. Если задать `Edge + Reserve` больше, чем
   вмещает плитка, значение молча клэмпится без ошибки/предупреждения.
2. Из плитки вырезается полоса шириной `N × 4` пикселей, взятая **от внутреннего края плитки**
   (края, ближнего к центру листа) — то есть внешняя часть плитки (декор дальше от угла) в
   рамку не попадает, если `N` меньше `T`.
3. Угловые куски всегда рисуются на экране РОВНО того размера, что запрошен (`N` единиц) — они
   не растягиваются под площадь элемента. Грани и центр, наоборot, гибкие: растягиваются на всю
   оставшуюся площадь (по умолчанию) либо тайлятся целыми плитками (`Repeat = true`, см. ниже).

### Соотношение Edge и Reserve

`Edge` и `Reserve` вместе определяют, СКОЛЬКО пикселей вырезать из плитки (`N = Edge + Reserve`)
— на уровне самой текстуры они визуально неразличимы, это одна непрерывная полоса. Разница
проявляется только в раскладке (layout) элемента:

- **`Edge`** — физическая кромка НА границе элемента: инсетит контент внутрь (уменьшает
  доступную область для содержимого — прибавляется к `Padding`).
- **`Reserve`** — вынос НАРУЖУ границы элемента: не трогает контент, а резервируется как
  минимальный `margin`, чтобы декоративный вылет рамки (например, узорные завитки по углам
  панели) не наезжал на соседние элементы сетки.

Наглядный пример из окна примеров мода («Стили → Спрайт-рамка (9-slice с запасом)»): синим
показана функциональная часть рамки (`Edge`, внутри неё — контент), золотым — декоративный запас
(`Reserve`), выходящий за пределы функциональной рамки наружу.

## Пример

```csharp
el.Style.Sprite = new SpriteFrame("MyMod/PanelFrame", corner: 12f);

// раздельные функциональная кромка и декоративный запас
el.Style.Sprite = new SpriteFrame("MyMod/OrnateFrame",
    edge: new Thickness(1f), reserve: new Thickness(3f));

// тайлинг: грани и центр размножаются целыми плитками вместо растяжения
el.Style.Sprite = new SpriteFrame("demo/pattern", 3f) { Repeat = true };
```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `AtlasKey` | `string` | — | Путь в `Textures/` или ключ, зарегистрированный темой. |
| `Edge` | `Thickness` | `1` (все стороны) | Функциональная кромка в единицах (1 ед = 4px текстуры): слой рамки на границе элемента, инсетит контент внутрь. |
| `Reserve` | `Thickness` | `Thickness.Zero` | Декоративный запас в единицах, выносится НАРУЖУ границы элемента (не инсетит контент; резервируется через margin). |
| `Repeat` | `bool` | `false` | Тайлинг: грани и центр размножаются целыми плитками от начала стороны, последняя частичная плитка обрезается, а не сжимается. `false` — растягиваются на всю площадь. |
| `Corner` (свойство) | `Thickness` | вычисляется | Суммарный размер угла/грани по сторонам (`Edge + Reserve`), в единицах. |

## Стили

Не самостоятельный визуальный слот — назначается через `Style.Sprite` любого элемента; сам факт
наличия `Sprite` переключает элемент на путь «спрайт» (`StyleMode.Sprite`).

## Методы

| Метод | Возвращает | Описание |
|---|---|---|
| `SpriteFrame()` (конструктор) | — | Пустой — задать поля вручную. |
| `SpriteFrame(string atlasKey)` (конструктор) | — | Только ключ атласа (без рамки/запаса). |
| `SpriteFrame(string atlasKey, float corner)` (конструктор) | — | Равномерный размер угла/грани в единицах: `Edge = 1`, `Reserve = corner - 1`. |
| `SpriteFrame(string atlasKey, Thickness edge, Thickness reserve)` (конструктор) | — | Раздельно по сторонам. |
| `static SpriteFrame.Off` (поле) | `SpriteFrame` | «Явно выключено»: рамки нет, даже если слот темы что-то задаёт. |

## События

Не применимо — это данные, не интерактивный элемент.

## Тайлинг (`Repeat = true`) — точная механика

Без `Repeat` грани и центр просто растягиваются на всю доступную площадь (обычное
масштабирование текстуры). С `Repeat = true` они вместо этого размножаются целыми плитками:

1. Исходная плитка-источник (весь центр `T×T` px или полоса грани) пересчитывается в единицы
   (той же системой 1 ед = 4px).
2. Число повторов по каждой оси = **округление вверх** отношения `размер_области_на_экране /
   размер_плитки` (в единицах) — то есть на всю доступную площадь укладывается целое число
   полных плиток плюс, как правило, одна неполная последняя.
3. **Последняя плитка по оси обрезается пропорционально остатку площади**, а не сжимается: если
   последняя ячейка вмещает только 70% плитки, из источника берётся ровно 70% его ширины/высоты
   от начала плитки — рисунок не искажается по пропорциям, просто последний повтор не влезает
   целиком и виден частично (отсюда фраза «частичная плитка обрезается» в описании компонентов).
4. Углы тайлингу НЕ подлежат никогда — они всегда рисуются одним неделимым куском фиксированного
   размера, вне зависимости от `Repeat`.
5. Каждая граница отдельного тайла привязывается к целому экранному пикселю — защита от швов
   при дробном масштабе интерфейса (UI Scale 1.25/1.5 и т.п.).

Практический совет: для больших областей выгоднее взять атлас с крупной плиткой `T` — число
тайлов на экране = площадь ÷ размер плитки, крупная плитка означает меньше повторов (меньше
затрат на отрисовку) и обычно менее заметный шов на последней частичной плитке.

## Поддержка механик

| Механика | Поддержка | Пояснение |
|---|---|---|
| Слоты темы | Да | Задаётся и в коде (`Style.Sprite = ...`), и в JSON темы (строкой или объектом). |
| Тайлинг | Да | Поле `Repeat` — см. раздел выше. |
| Анимация | Косвенно | `Style.Animation` элемента-носителя работает независимо от наличия спрайта. |
| Disabled/Hover-fade | Не применимо | Это статичные данные рамки, а не интерактивный элемент. |
