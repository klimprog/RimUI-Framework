# Начало работы

RimUI Framework — библиотека для модов RimWorld, которая строит интерфейсы в стиле веб-разработки:
12-колоночная сетка, готовые компоненты (кнопки, поля, таблицы, графики...),
темы со своими цветами и спрайтами. Мод ничего не патчит в игре и не требует Harmony — это чистая
библиотека, которую подключает ваш мод.

Рендеринг — **immediate-mode**: каждый кадр вы заново описываете дерево элементов (какая сетка,
какие компоненты, какие у них значения), а фреймворк сам считает размеры (`Measure`), расставляет
элементы (`Arrange`) и рисует их (`Emit`). Не нужно вручную пересчитывать позиции при изменении
контента — просто опишите желаемое состояние на основе текущих данных, как в React/Immediate GUI.

## Подключение

1. Добавьте зависимость от `RimUI Framework` в `About.xml` вашего мода:
   ```xml
   <modDependencies>
     <li>
       <packageId>klimprog.rimui</packageId>
       <displayName>RimUI Framework</displayName>
     </li>
   </modDependencies>
   <loadAfter>
     <li>klimprog.rimui</li>
   </loadAfter>
   ```
2. В сборке C# подключите `RimUI.dll` (лежит в `Assemblies/` мода) как референс.
3. Все публичные типы — в пространствах имён `RimUI.Core`, `RimUI.Layout`, `RimUI.Styling`,
   `RimUI.Components`, `RimUI.Elements`, `RimUI.Animation`, `RimUI.Adapter`.

## Первое окно

```csharp
using RimUI.Adapter;
using RimUI.Elements;
using RimUI.Layout;

var root = new Grid();
root.Cell(12, Button.Make("Привет, RimUI!"));

var window = new ModalWindow(root) { Title = "Моё окно" };
window.Show();
```

`ModalWindow` — обычное окно RimWorld (`Verse.Window` под капотом), с шапкой (заголовок + кнопка
закрытия), телом и, при необходимости, футером с кнопками. Подробности — раздел «Окна».

## Инструменты мода

Доступны и в настройках мода, и в Debug actions (DevMode → Debug actions → RimUI):

- **Окно примеров** — витрина всех компонентов фреймворка, живые интерактивные образцы каждого
  из них (сама витрина на 100% построена на этом же фреймворке).
- **Конструктор интерфейсов** — визуальная сборка сетки блоков мышью, с экспортом готового
  C#-кода в буфер обмена.
- **Экспорт шаблона темы** — копирует в буфер обмена полный JSON со всеми слотами и ключами
  темы (со значениями по умолчанию).

## Как читать эту документацию

Каждый компонент — на отдельной странице с одинаковой структурой: описание → пример кода →
таблица параметров → таблица стилей → методы → таблица событий → таблица поддержки механик
(анимация, спрайт, тайлинг, disabled, hover-fade). Меню слева (раскрывающийся блок «Оглавление»
вверху каждой страницы) и ссылки «Пред./След.» внизу — для навигации между всеми страницами по
порядку.
