# AudioPlayer

Аудио-хелпер: плейлист из папки вашего мода (`.ogg`/`.wav`/`.mp3`), управление —
Play/Pause/Next/Prev/Seek. Это НЕ готовый плеер, а набор методов — интерфейс к нему (кнопки,
полоса позиции) собираете сами из обычных компонентов фреймворка.

`RimUI.Adapter.AudioPlayer` (не `UiElement` — обычный класс-хелпер)

## Пример

```csharp
var audio = new AudioPlayer();
audio.LoadFolder(System.IO.Path.Combine(MyMod.RootDir, "Audio"));

var playBtn = Button.Make("Play/Pause");
playBtn.OnClick = () => { if (audio.IsPlaying) audio.Pause(); else audio.Play(); };

var status = new CustomDraw
{
    Style = { Width = 260f, Height = 20f },
    OnDraw = (list, rect, style, ctx) =>
    {
        string txt = (audio.IsPlaying ? "> " : "|| ") + (audio.CurrentName ?? "-");
        list.Add(DrawCommand.Label(rect, txt, new TextStyle { VAlign = VerticalAlign.Middle }));
    }
};
var pos = new ProgressBar(() => audio.DurationSec > 0f ? audio.PositionSec / audio.DurationSec : 0f)
    { ShowText = false, BarHeight = 6f };
```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Count` (свойство) | `int` | `0` | Число треков в плейлисте. |
| `Volume` | `float` | — | 0..1, домножается на `Prefs.VolumeGame`. |
| `IsPlaying` (свойство) | `bool` | `false` | Воспроизводится ли сейчас. |
| `CurrentIndex` (свойство) | `int` | `-1` | Индекс текущего трека (-1 = ничего не выбрано). |
| `CurrentName` (свойство) | `string` | `null` | Имя текущего трека без расширения. |
| `PositionSec` (свойство) | `float` | `0` | Позиция в текущем треке, сек. |
| `DurationSec` (свойство) | `float` | `0` | Длительность текущего трека, сек. |

### Важный нюанс загрузки: блокирующий таймаут 3 секунды

Загрузка клипа синхронная: `Play(index)` внутри опрашивает `UnityWebRequest` в цикле
busy-wait (`Thread.Sleep(1)` за итерацию) до готовности, но не дольше **3000 мс**. Локальный файл
обычно грузится за доли миллисекунды, но если файл битый или недоступен — **это блокирует главный
поток игры (и, соответственно, кадр) на весь таймаут, вплоть до 3 секунд**, прежде чем
загрузка будет признана неуспешной и в лог уйдёт предупреждение. Клипы кэшируются по индексу —
таймаут грозит только при ПЕРВОЙ загрузке конкретного трека; повторные `Play(index)` того же
трека блокировки не создают. Учитывайте это при работе с треками из непроверенных источников
(например, файлами, добавляемыми пользователем во время игры).

## Стили

Не применимо — это не визуальный элемент, а класс-хелпер управления воспроизведением.

## Методы

| Метод | Возвращает | Описание |
|---|---|---|
| `AudioPlayer()` (конструктор) | — | Создать плеер (пустой плейлист). |
| `LoadFolder(string absDir)` | `void` | Загрузить весь `*.ogg\|*.wav\|*.mp3` из папки по алфавиту. |
| `Load(IList<string> paths)` | `void` | Загрузить явный список абсолютных путей. |
| `ListNames()` | `IList<string>` | Список имён треков; текущий помечен `"> "` спереди. |
| `Play(int index)` | `void` | Начать/продолжить трек по индексу. |
| `Play()` | `void` | Продолжить текущий трек либо начать с первого, если ничего не выбрано. |
| `Pause()` | `void` | Пауза. |
| `Next()` | `void` | Следующий трек (зацикливается). |
| `Prev()` | `void` | Предыдущий трек (зацикливается). |
| `Seek(float deltaSec)` | `void` | Перемотка в рамках текущего трека (клампится 0..длина). |
| `Dispose()` | `void` | Освобождает ресурсы (`AudioSource`/клипы) — обязательно вызывать при закрытии окна/выгрузке плеера. |

## События

Собственных событий/колбэков нет — состояние читается пассивно каждый кадр.

## Поддержка механик

| Механика | Поддержка | Пояснение |
|---|---|---|
| Стиль/Спрайт/Анимация | Не применимо | Это не `UiElement` — интерфейс к плееру собирается из обычных компонентов, у которых эти механики уже описаны на их страницах. |
| Disabled | Нет | Своего понятия «отключён» нет — блокировку кнопок делает вызывающий код. |
| Hover-fade | Не применимо | Нет собственного визуального представления. |
