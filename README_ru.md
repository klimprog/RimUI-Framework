## Описание

**RimUI Framework** — библиотека для мододелов RimWorld для быстрого построения интерфейсов:
12-колоночная сетка, стили (отступы, фон/градиент/изображение, бордюр,
скругление, тень), темы со значениями из JSON. Не патчит ваниль,
не требует Harmony и не тянет рантайм-зависимостей.

Сам по себе мод ничего в игру не добавляет — это зависимость для других модов. Если он
установлен, но ни один активный мод его не использует, никакого эффекта на игру нет.

## Совместимость

RimUI Framework — библиотека, а не контент-мод. Из этого следует:

- **Не патчит игру.** Harmony не требуется, ванильные классы не переопределяются, игровые окна не
  подменяются. Фреймворк рисует только внутри окон, которые открывает использующий его мод.
- **Не добавляет и не меняет дефы.** В игре не появляется ни одного предмета, здания, события или
  исследования — папка `Defs` пуста.
- **Ничего не пишет в сохранение.** Нет `GameComponent`, `WorldComponent` и `Scribe`-полей:
  удаление мода не портит существующие сейвы.
- **Нет рантайм-зависимостей.** Только код самого фреймворка, без сторонних библиотек.
- **Поддерживается RimWorld 1.6.**

**Порядок загрузки:** RimUI Framework должен загружаться **до** модов, которые его используют —
в их `About.xml` прописывается зависимость и `loadAfter`.

**Конфликты.** Библиотека не вмешивается в чужой интерфейс, поэтому конфликтовать с другими
UI-модами ей нечем. Если RimUI Framework используют сразу несколько модов, все они работают с одной
общей копией: дублирования сборки не происходит.

## Инструменты для мододелов

Все инструменты доступны прямо из настроек мода: **Опции → Настройки модов → RimUI Framework**.

- **Окно примеров** — живая витрина всех компонентов фреймворка (сама на 100% построена
  на фреймворке). Кнопка «Открыть окно примеров».
- **Конструктор интерфейсов** — визуальная сборка сетки блоков с экспортом готового
  C#-кода в буфер обмена. Кнопка «Открыть конструктор интерфейсов».
- **Экспорт шаблона темы** — полный набор слотов и ключей темы в буфер обмена, для правки
  под себя. Кнопка «Экспортировать шаблон темы в буфер обмена».

Те же три инструмента продублированы в **Debug actions → RimUI** (нужен режим разработчика).
